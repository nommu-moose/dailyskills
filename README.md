# dailyskills

Installable skills for ordinary study. Not the development bundle in the sibling `skills` repo.

Nothing here is an installable skill yet. The design conversation that decided the set is in [design-conversation.md](design-conversation.md). Write the skills into this folder when that conversation says to, in the same shape as `skills`: one folder per skill with a `SKILL.md`, shared notes beside them and not themselves skills, and a small installer when there is something to install.

## Settled split

| Skill | Job |
| --- | --- |
| `study` | General tutoring and study management. Modes: Session, and Skeleton when there are no notes and only a vague list of what should be known. Also the skill to name when unsure. |
| `studyread` | Condense a source under a lens and a length budget. |
| `studynotes` | Critique how the user writes and thinks in their own notes. They keep the pen. |
| `studyspan` | From real summaries or a real core: Gap, or Periphery. Tutoring in both. Notes only when that mode allows them. |
| `studymark` | Mark an essay or answer and coach another way through the question. |

A heading list is not a summary. Skeleton stays in `study`. Gap stays in `studyspan`.
