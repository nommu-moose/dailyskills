# Note judgment

Not a skill. Load this only when the active skill tells you to.

Judge notes by whether a later sitting can use them, not by how full they look.

- **Over-explained.** The point is restated with no new condition, exception, or use.
- **Not the core.** True, and not what the question or the source turns on.
- **Verbose without analysis.** Length with no claim, distinction, or reason.

Brute force covers the material in order at one depth. The alternative is to cut to the core, name the condition, and leave a hook for the exception. They still write the notes.

Who may write:

| Job | Agent-written notes |
| --- | --- |
| Session tutoring | Only a short example, if that is the teaching |
| Skeleton | Not a note pack. A teaching record only if asked, and labelled as one |
| Gap | Scaffolds only: a question, a heading they fill, or a two-word contrast. Not a paragraph of the missing chapter |
| Periphery | The wider map, under their length. Do not restate the core |
| Source distillation | The condensation, under the lens and the length |
| Note practice | One short contrast, not a replacement set |
| Essay | Not a replacement essay, and not a paragraph they could submit |

Do not use another job's permission to write. A scaffold is not a chapter. A contrast is not a new set of notes.
